- Request for Guide Change

- 1. Death of the Guide
- 2. Serious health issue of Guide
- 3. Transfer of the Research scholar to another University
- 4. Grievance of Research scholar

## Slide 26

- 4. System should load the Guide/Co-Guide to choosing preferences based on the following Conditions if the request type 1-5 have been selected.
- The Guide/Co-Guide should have vacancy matrix available of the respective category of the student.
- The Vacancy matrix created for the Guide will be applicable to Co-guide as well while allocating.
- If the request is to change Guide/Co-Guide, then load all the employees except existing guide/change or Co-Guide.
- The Faculty loaded should belong to the same area of research to which the student has chosen.
- Based on the request, the guide/Co-guide research faculty type mapped faculties should be loaded,
- 5. System Should allow only the online fees to be paid based on the fee configured for the request type. No offline fees is allowed.
- 6. Once the student has requested for a Guide/Co-Guide, their allocation vacancy matrix seat count related to the student should be locked and should be released only if the request has been released.
